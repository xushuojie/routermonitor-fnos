# NAS Monitor 安装与使用说明书

适用版本：飞牛 **1.3.0-5**、Android **1.1.5-adaptive-test**。

## 1. 下载与校验

从 [downloads](../downloads/) 下载 FPK、APK 和 `SHA256SUMS.txt`。GitHub 文件页面点击 **Download raw file** 保存安装包。源码可在仓库首页选择 **Code → Download ZIP**。

Linux/macOS 在安装包所在目录运行 `shasum -a 256 -c SHA256SUMS.txt`，Linux 也可使用 `sha256sum -c SHA256SUMS.txt`。Windows 使用 `Get-FileHash 文件名 -Algorithm SHA256`，与校验文件逐项对照。

## 2. 安装飞牛服务端

需要 x86-64 / amd64 飞牛 NAS，已安装并可运行 Docker。

1. 在飞牛应用中心手动安装 `routermonitor-fnos-1.3.0-5-amd64.fpk`。
2. 安装向导填写服务端口和两次一致的非空管理员密码。默认端口为 `18199`，可设为未占用的 `1024–65535` 端口。
3. 启动 NAS Monitor，在浏览器访问 `http://NAS局域网IP:端口`，如 `http://192.168.1.10:18199`。
4. 使用安装时的管理员密码登录。安装包内含离线 Docker 镜像。

升级时端口、密码留空沿用原值；填写两次新密码可重设管理员密码。升级及卸载保留 `routermonitor-fnos-data` 数据卷，保存 Token、硬件设置和历史数据。不要手动删除此卷，除非需要清空数据。升级前建议备份数据卷。

## 3. 网页控制台

**数据展示**显示网络、CPU、内存、磁盘读写、GPU、UPS、温度、24 小时流量、逐卷容量和采集状态。缺少数据源时显示不可用或原因。

**设置**用于选择存储卷、网卡、温度来源、GPU、UPS 和采集频率，并管理显示端 Token、管理员密码、配置导入导出和脱敏诊断。自动发现是默认值，不需要在安装向导填写硬件参数。

| 设置 | 使用说明 |
| --- | --- |
| 存储 | 自动发现本地磁盘、飞牛数据卷及支持的 USB 文件系统；可手选卷或填写宿主机路径。排除网络共享、伪文件系统及容器挂载；重复挂载及 Btrfs 子卷去重 |
| 卷掉线或换盘 | 选定卷掉线时不输出不完整合计。同路径换盘后，移除该路径并保存，再重新选择以更新身份 |
| ZFS | 同池数据集可能共享空间；无法可靠相加时保留逐卷数据，合计标记不可用 |
| 网卡 | 选择需要统计的接口；避免把物理接口与其桥接、聚合接口重复统计 |
| 温度 | 自动取对应类别最高值，或指定传感器、关闭摘要 |
| GPU | 自动、手选或关闭；AMD 使用系统利用率，Intel 使用引擎计数或宿主机 `intel_gpu_top`，NVIDIA 使用已有 `nvidia-smi`；不自动安装驱动或工具 |
| UPS | 支持本机 NUT socket 与远程 NUT 只读查询；填写地址、端口、设备名。没有有功功率数据时不把 VA 当作 W |
| 采集频率 | 实时：网络 0.2 秒／状态 1 秒；标准：0.5 秒／1 秒；低占用：1 秒／2 秒；历史持久化为 5 秒 |

## 4. 连接 Android 与 ESP8266

在 NAS 网页 **设置 → 设备与管理 → 安卓 / ESP8266 显示端** 获取局域网服务地址，查看或复制只读 Token。地址从 NAS 网卡读取，端口使用实际监听端口；多网卡时选择显示设备可以访问的地址。通过飞牛远程入口打开网页时，显示端仍应使用这里列出的局域网地址。

管理员密码用于网页登录；只读 Token 用于读取监控指标，不能互相替代。自定义 Token 支持 1–512 个 ASCII 可见字符，不含空格或中文，两次输入一致后保存立即生效。旧 Token 失效，所有 Android / ESP8266 显示端都要同步修改。

### Android

1. 安装 `routermonitor-android-1.1.5-adaptive-test.apk`，按系统提示允许该安装来源。
2. 打开 **NAS Monitor 布局测试**，填写 NAS 服务根地址和只读 Token。地址不要附加 `/status` 或 `/net`。
3. 点击右上角或长按画面打开设置。Android 17 局域网访问需要授权；拒绝后可进入系统设置恢复。
4. 按需设置日间亮度、夜间时间与亮度、平板卡片展开、OLED 保护和闲置降亮度。

此 APK 使用独立包名 `io.github.routermonitor.fnos.layouttest` 和测试签名，可与旧正式版并存，首次安装需重新配置。相同签名的 1.1.1–1.1.4 测试版可覆盖升级保留设置；自行编译的默认 debug 签名可能不同。

设置风格按系统版本选择：Android 4.3–4.4 为 Holo，Android 5–11 为 Material，Android 12+ 为随应用打包的 Material 3。数据画面支持横竖屏、沉浸式全屏和字体缩放；短窗口可滚动。夜间默认 23:00–07:00，采用上海时区。OLED 保护默认开启，使用黑底、微移与闲置降亮度，不能保证避免烧屏。

### ESP8266

本次未更新固件。保持已有固件，进入设备配网页面设置 NAS 地址、端口与 Token；接线、屏幕型号及刷写步骤见 [主 README](../README.md)。服务端继续兼容 `/status`、`/net`、`/health`、Bearer Token、v2 及 `display=1` 接口。

## 5. 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 网页打不开 | 检查应用与 Docker 状态、服务端口占用和 NAS 防火墙；确认访问的 IP 和实际端口 |
| 网页能用，显示端无法连接 | 先在显示端浏览器测试 NAS 局域网地址；检查 Wi-Fi 网络、访客隔离、地址端口及 Android 局域网权限 |
| 显示端鉴权失败 | 从网页重新复制只读 Token；检查是否刚修改过 Token，避免误填管理员密码 |
| GPU、温度或 UPS 不可用 | 在采集能力及诊断中查看原因；检查驱动、宿主机工具和相应硬件设置 |
| 容量合计不可用 | 检查手选卷掉线、卷身份变化、重复挂载或 ZFS 共享池空间 |
| APK 无法覆盖安装 | 核对是否为同包名、同签名的测试版；正式版与本次测试版并存，不共享设置 |

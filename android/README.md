# Android NAS 显示终端

面向 Android 4.3（API 18）旧手机的原生显示端，适合横屏常亮。Java + Android Canvas，无 WebView、第三方运行库或 Google Play 服务依赖。与 ESP8266 读取同一 Docker 服务，不在手机上重新统计 NAS 流量或容量。现代 Android 对低目标版本 APK 有额外安装限制，本模块不承诺覆盖所有新系统。

## 安装和连接

安装 `nas-monitor-android.apk`，打开 **NAS Monitor**，填写 NAS 服务根地址（如 `http://192.168.x.x:18199`）和管理网页提供的**只读 Token**。不需要管理员密码。服务端使用当前项目的 v2 接口；建议在可信局域网连接。

- 点击右上角“设置”、长按画面或按返回键打开设置。
- 默认 500ms 拉取网络，提供 200ms 选项；状态每秒请求一次。
- 点击轮播区翻页，默认每 5 秒自动切换，并作 180ms 横向滑动。
- 可调亮度 10–100%，默认 30%；可选上海时间 23:00–07:00 调暗至 10%。
- 显示页面在前台时保持屏幕开启；离开应用停止网络任务并允许正常休眠。没有后台常驻或开机自启服务。

Token 只保存在应用私有 SharedPreferences，禁用系统备份，配置不打包到 APK、不写入日志；不向重定向地址转发 Token。已 root 的手机不具备可靠的应用数据隔离。HTTP 沿用服务端配置，传输不加密；不要在此终端输入 NAS 管理员密码。

以横屏可用画布为基准等比例适配，不依赖 Android 4.4 才引入的沉浸式模式。不同设备的系统栏可能导致可用画布较小。

## 数据与性能

- `/net?v=2&since=…&epoch=…`：服务端每 200ms 采样，响应最多 4 个点。500ms 模式批量读取采样，画面约每秒更新两次；200ms 模式约每秒更新五次，不声称达到 60fps。网络延迟超过补点窗口时，按 `gap` 断开曲线。
- 网速数字采用服务端 `rate` 的约 1 秒平均值。曲线保留最多 320 个点，只展示最近 60 秒；共用从零开始的纵轴。上限按 1/2/5 档位扩展，降低需持续 10 秒，避免抖动。
- `/status?display=1&v=2`：每秒拉取；温度、流量和容量仍遵循服务端自己的采样周期。遵守 `valid`、`null`、响应年龄和温度/容量年龄，不把缺失数据转换为零。
- 时钟用 HTTP `Date` 校准，再用单调时钟推进；首次未连接时使用手机时间。统一上海时区，不修改系统时钟。
- 两条独立、无重叠的轮询任务，连接/读取超时各 1.5 秒；失败按 1/2/4/8/10 秒退避。响应最多 16KB，不加载网页或远程代码。
- 仅在数据、秒钟和短时翻页动画变化时重绘。`NasMonitor` 日志每 30 秒记录请求计数、数据年龄和绘制耗时，不含连接凭据。

## 构建

需要支持 `javac --release 8` 的 JDK，以及 Android SDK 的 `platforms;android-18`、`build-tools;35.0.1`。构建直接使用官方 `javac`、D8、aapt、zipalign、apksigner，不需要 Gradle。

```sh
export ANDROID_HOME=/path/to/android-sdk
export JAVA_HOME=/path/to/jdk
python3 android/build.py
adb install -r android/build/nas-monitor-android.apk
```

默认使用本机已有的 `~/.android/debug.keystore`，仅供个人开发。正式构建通过环境变量 `ANDROID_KEYSTORE`、`ANDROID_KEY_ALIAS`、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_PASSWORD` 指定私有发布签名；更新必须保持同一签名。不要提交签名私钥和密码。APK 启用 v1 签名以兼容 Android 4.3。

构建会运行一个普通 Java 自检，覆盖单位进位、无效值、纵轴范围、历史上限、重复序号和缺失点。`android/build/` 是忽略的生成目录，APK 不包含预填地址、Token 或用户配置。

本模块的版本独立于 ESP8266 固件；v1.0.2 Release 的既有附件不含此 Android APK。

## 实机验证（2026-09-05）

OPPO R2017，Android 4.3，540×960 / 240dpi，系统报告约 849MiB 内存。发布签名 APK 约 25KB，已安装；覆盖安装后地址与 Token 保留。全屏显示区域为 960×540，网速、时钟、硬盘读写、四页轮播及底栏已检查。

- 两档各采样约 62 秒：500ms 模式 PSS 约 14–20MiB；200ms 模式约 24–28MiB。PSS 包含共享内存的分摊，不能与手机标称 RAM 直接等同。
- 200ms 模式实测连续 30 秒完成 150 次网络请求；500ms 模式约 60 次，两档状态请求约 30 次，正常联网期间未记录失败。
- 绘制日志观察到约 40–76ms 的单次最长耗时，包括线程调度影响；不能据此宣称每帧 60fps。默认保留负载较低的 500ms。
- 离开应用后，连续 10 秒该 UID 的网络字节计数保持不变。通过系统设置关闭手机 Wi-Fi，实机显示连接中断及无效值；重新开启后自动恢复。
- 未进行 24 小时压力测试、供电功耗测量或其他手机的实机验收。手机功耗不能沿用 ESP8266 的约 0.55W 测量结果。

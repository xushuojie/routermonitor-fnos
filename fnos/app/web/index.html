安卓 / ESP8266 显示端

检测中

显示端与 NAS 处于同一局域网时，填写下方局域网服务地址和只读 Token。多网卡设备请选择显示端能够访问的地址。

自定义只读 Token

支持 1–512 个英文、数字或符号，不含空格或中文。保存后立即生效，安卓和 ESP8266 需同步更新；旧 Token 将失效。

只读 Token 可以获取指标，不能登录网页或修改数据源。下方地址从 NAS 网卡读取，端口为应用实际监听端口。

管理员密码

管理网页登录密码，支持任意非空密码。

更新后，所有网页管理员会话退出；不影响 ESP。

配置与诊断

导出包含接口选择和别名，不包含管理员密码或 Token。导入后先预览，再应用。

查看采集能力与支持范围

没有对应驱动、传感器或只读挂载时显示不可用，不用 0 代替未知值。可在数据展示页面核对每项采集状态和不可用原因。

存储空间

自动模式发现已挂载的本地存储卷。手动模式可选择系统盘、外接盘或自定义挂载路径。

填写飞牛宿主机的绝对路径。重复挂载自动去重，未挂载的物理硬盘没有可统计的文件系统空间。

温度与显卡

列表来自当前硬件检测。无驱动或权限时会显示原因，其他指标仍可正常使用。

功率来源与读数

三个来源分别显示；平台与 CPU 功率不能相加，也不等于插座整机功率。无传感器时显示不可用，不估算。

手动指定时只使用该来源；不可用时不会偷偷切换。更改后点击下方“保存硬件设置”。

UPS 连接配置
